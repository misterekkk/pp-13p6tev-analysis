# Dane referencyjne ALICE

## `ins1797443/`: widma π, K, p przy √s = 13 TeV

ALICE, *Production of light-flavor hadrons in pp collisions at √s = 7 and 13 TeV*,
Eur. Phys. J. C 81 (2021) 256, [arXiv:2005.11120](https://arxiv.org/abs/2005.11120).
HEPData: [ins1797443](https://www.hepdata.net/record/ins1797443),
DOI [10.17182/hepdata.100303.v1](https://doi.org/10.17182/hepdata.100303.v1).
Pliki CSV pobrane z HEPData bez zmian. Pełny opis każdej tabeli jest
w nagłówku pliku.

| Plik | Zawartość |
|---|---|
| `Table_1.csv` | π⁺ + π⁻: (1/N_ev) d²N/(dpT dy), \|y\| < 0.5, INEL |

| `Table_6.csv` | p + p̄, jak wyżej |
| `Table_21.csv` | (K⁺ + K⁻)/(π⁺ + π⁻) w funkcji pT |

Niepewności statystyczne i systematyczne są podane osobno. Niepewność normalizacji ±2.6% nie jest
w nich uwzględniona (opis tabel 1, 2, 6).
